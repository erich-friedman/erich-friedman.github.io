Contributor Guidelines

To contribute improved configurations for inclusion on this page, please send me an email containing:

1) A descriptive title. Do not reply to a previous email exchange if you are including new packings.

2) A picture of the packing itself. It should be the same orientation, color, pixel size, file type, and name as the picture it is replacing, with no border or text. (An exception is packings in the "Maximize Total Perimeter" category, where you have some flexibility in colors as long as you use a rainbow palette in which close sizes correspond to close colors.)

3) The radius or side length of the packing to 5 decimal places. If possible, include the exact value.

4) Your full name, for attribution purposes.

5) If you are a new submitter, some description of the program/method you used.

Extending an existing category is acceptable, but only up to n=50.

If you are submitting a large batch of pictures that belong on different pages, sort the pictures by page and put them in folders with appropriate names. If this is not possible, send me separate emails so that the file names do not interfere.

If you have any comments or questions, feel free to email me.
